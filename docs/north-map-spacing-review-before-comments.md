# 雙北・桃園路網調整紀錄

本版為 5200 × 4950 SVG，182 站體、179 組可見站名、38 組副站名、195 站碼、17 個共站黑框及 9 組站外虛線。A14、A23 仍僅為灰色預告，不進入挑戰題庫。

## 本次修正

- 景平與景安同高；象山至廣慈/奉天宮恢復水平。
- 新北投、小碧潭及淡海分支縮短；淡水至紅樹林縮短。
- 劍南路至內湖加寬，東湖至南港展覽館高差縮至 190。內湖至東湖整段高差 150、寬 520，轉彎前斜段採 5:1，無逆向折返。
- 西門抬高；江子翠至西門以斜線、水平、斜線分段上升。龍山寺左右各有水平直線。
- 轉乘黑框及路線交會均以站點中心置中。頂埔碼序 LB01/BL01，景安碼序 Y11/O02。
- 機捷三重站轉角不再提前圓滑切過站內；路線確實通過站點中心，控制點仍維持圓角。
- 安坑新和國小至安康改左下 45 度；十四張至新和國小、安康至雙城仍水平。移除輕軌十四張站名字樣，保留 K09 端點及虛線。
- A03/Y20、R27/V01 分別共用一組站名；其他同名分離站仍各自標名。
- A01 取消鐵路轉乘資訊標籤；北門及北捷台北車站的機捷標籤保留。
- 東門至行天宮垂直軸右移；中正紀念堂站名置於左下；南港名稱固定在站點上方。
- 貓空纜車淺藍、不編號，O/Y 黑碼、輕軌圓形、捷運圓角矩形、端點實心等既有規則不變。
