# 雙北・桃園：12 輪站距調整與 3 輪校驗

本版保留 11 系統、17 段站序、176 個站體、173 個站名與 38 組副站名。加入 197 個站碼、31 個黑框轉乘符號；捷運填色、淡海與安坑輕軌描邊，各線端點填色。原始附件座標仍留在資料與 SVG metadata，顯示座標則依本次站距要求調整。

所有數值為 SVG 畫布單位，並非實際公里。等式約束固定水平、垂直及原有 45 度軸向；微小圓角用二次貝茲曲線表示。每輪都重新求解座標、量測全部系統，記錄本輪最大位移與符號碰撞，並非重複宣告相同狀態。

## 3 輪校驗

1. **資料與幾何**：38 項 Node 測試通過。逐線比對完整題庫站序、站名與副站名，核對站碼、路線軸向、端點填色、分岔、步行連接、圓角路徑與全部外框碰撞。另量測全部 55 組系統配對的外框間距。
2. **互動與產出**：12 項介面測試與 Vite 正式建置通過。縮放、全圖／市中心、展開／Esc、切換路線及挑戰流程均正常；下載 SVG 與同一份網頁資料一致。
3. **瀏覽器視覺**：全圖、300% 市中心與 274% 西側檢視通過；最後再核對 3200 × 3300 畫布。DOM 實際邊界量測為 176 個站體、173 個站名、197 個站碼、38 組副站名及 31 個黑框；站名重疊 0、外框重疊 0、文字壓框 0。底部兩句來源標示完整，瀏覽器沒有錯誤日誌。
