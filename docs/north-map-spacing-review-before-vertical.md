## 五遍檢查紀錄

1. **站距與定位**：以 src/north-map-comment-reference.js 保存修改前座標，再逐項量測。象山終段與前方均為 178；BL08—BL09 約 162.2 → 259.3；A15—A23 總高差約 1620.3 → 965.2。O14—O21 各段約 219.88～220.10，最大差不到 0.22。三段市中心橫向軸由 381.83 縮至 300，O11/R13—O10 縮至 220。
2. **接線與幾何**：14 輪調距後，末輪站框重疊 0、逆向站序 0，方向約束誤差 9.09e-13。A02/A03 同高且 A02 前後軌道水平，龍山寺兩側仍有水平直線；BL/Y 保留指定軸向，並增加原座標保留權重以減少變形。BL 最大站體位移約 108.0、Y 約 71.5；包含本次指定的站距及站體變更。
3. **文字及符號**：178 組標籤的規劃包圍盒互撞 0；實際瀏覽器亦確認互撞 0、遮住站體 0。南港使用居中錨點，站名及台鐵／高鐵位於站體下方。台北車站機捷資訊列於兩個鐵路提示下方；A03 上方顯示共享名稱，A02 不重複標名。
4. **程式與輸出**：42 項 Node 測試、12 項 UI 測試均通過，正式建置成功；額外 20 項標註檢核全通過。頁面、public 下載 SVG 與 dist 輸出一致。
5. **放大視覺檢查**：實際瀏覽器以 450% 檢視市中心、環狀線南段及東北側，另檢視全圖、機捷與淡海輸出預覽。確認指定配色、提示分行、站距與連線位置，瀏覽器沒有 error/warn。

所有長度及位移均為 SVG 畫布單位，不代表實際距離。55 組系統的非共站站框最小邊距約 22.42；圖面無站名引線。灰色 A14／A23 仍為圖面預告，不進入挑戰題庫。
