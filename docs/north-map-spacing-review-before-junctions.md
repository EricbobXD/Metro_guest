# 雙北・桃園：白底站碼與同側站名，14 輪調整＋3 輪校驗

本次重新完成 14 輪幾何求解與量測，沒有沿用上一版的輪次計數。保留 11 個系統、17 段站序、176 個站體、173 個站名、38 組副站名、197 個站碼與 31 個黑框。

一般捷運站碼改為白底、線色外框的圓角矩形；淡海與安坑輕軌改為白底、線色外框的圓形。機場捷運站碼及每個系統的端點維持實心；共站內各站碼分別判定，所以紅樹林 R27 空心、V01 實心，十四張 Y08 空心、K09 實心。

象山至「廣慈/奉天宮 | 松山慈惠堂」依最新指示改成右上 45 度。其他站序、分岔、轉乘及主要軸向維持原規劃。原始附件座標仍保存在來源資料與 SVG metadata，顯示座標另外儲存。

## 同側站名

以 36 組連續路段固定標籤方向，碰撞時只在同一側移動，不可換到另一側。R 線明德至中正紀念堂主幹的站名固定在右側，台北車站因北捷／機捷分離站體而使用上方共用標籤。145 個標籤完全不需沿線偏移，其餘保留短引線。一般非轉乘站標籤至站心最遠 43；全部標籤最遠 84，出現在台北車站共用站名。沒有標籤文字框穿過路線。

## 3 輪校驗

1. **資料與幾何**：39 項 Node 測試通過。完整站序、176 個站體、173 個站名、38 組副站名、站碼、全部端點、圓形／矩形規則、黑框、同側排列、右上 45 度終段、分岔與步行連接均逐項驗證；另外量測全部 55 組系統的站碼外框邊距。
2. **介面與輸出**：12 項介面測試及 Vite 正式建置通過。全圖／市中心、縮放、展開、Esc、單線切換、挑戰與計時流程正常。網頁與下載 SVG 使用同一份產生器；4800 × 4950 圖面及 PNG 預覽均等比例輸出。
3. **瀏覽器實際圖面**：檢查全圖、450% 市中心、450% 南側輕軌。實際 DOM 邊界量測：站名重疊 0、站框重疊 0、文字壓站框 0。逐一核對 R18 白底矩形、K08 白底圓形、A04 實心矩形，以及 K09／V01 端點實心。底部兩句來源標示完整且在畫布內。最後以重新載入確認正式圖面能正常顯示。
