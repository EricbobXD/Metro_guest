# 站站練習 Rail Sprint

React + Vite 的台灣鐵道路網練習網站，無後端、無帳號。練習紀錄僅存於瀏覽器 localStorage。

## 啟動

```sh
npm install
npm run dev
```

開啟終端顯示的本機網址。正式版本使用 `npm run build`，輸出在 `dist/`；可用 `npm run preview` 預覽。

## 功能

- 台鐵 243 站、17 組路線（含花蓮臨港線）；高鐵 12 站；雙北＋桃園、台中、高雄捷運與輕軌。
- 全圖限時填空：自由輸入或點選站序空格，轉乘共站自動同步。
- 最少站數：使用 BFS 距離判斷每個下一站，接受所有等長最短路徑，起終點不必填。
- 轉乘挑戰：複選本站服務路線及可轉乘系統，包括資料中列出的台鐵、高鐵轉乘。
- 副站名模式、台／臺正規化、高鐵可選 30 秒／1 分鐘，其餘系統可選 10／25／30 分鐘、完成率與本機最佳紀錄。
- 高鐵開放全圖填空及轉乘站名挑戰，固定僅站名；北捷歷史版本及最短公里數尚未開放。
- 雙北＋桃園全路網為 5550 × 4950 SVG，11 系統、18 段路徑、186 站體、183 組可見站名標籤、38 組副站名、201 站碼。依附件及後續指定線形完成 14 輪站距調整，各路段固定標籤側邊，無站名引線。象山終段水平，文湖北側拉寬，安坑改水平／左下 60 度／水平，共站黑框與路線交會置中。
- 共站依指定順序排列，保留 18 個黑框；8 組站外虛線，紅樹林與新北產業園區共用站名，K09 不顯示站名；三重 O15/A02 合併為共站轉乘，其他同名分離站各自標名。A14 機場第三航廈與 A23 中壢車站為灰色預告，未加入挑戰題庫。北門及北捷台北車站加機捷提示；纜車淺藍且不編號，小碧潭支線黃綠色，淡海全線統一主線色。來源及非官方標示完整保留。
- 提供全圖、市中心、縮放、拖曳、方向鍵、Home、展開檢視及下載 SVG。捷運圓角矩形、輕軌圓形，白底線色外框；機捷及端點實心。北投／七張等支線分岔不加轉乘框。
- 全路網複習圖直接顯示完整站名與副站名；副站名放在站名下方，以「|」分隔。共站轉乘只標一次，除指定共享與隱藏名稱外，分離站體即使同名也各自標示，沒有副站名的站點不加空白分隔符號。挑戰中的站圖、單線逐站圖及其他城市仍使用原有完整題庫；淡海輕軌各支線合併為同一路線選項。

## 指定座標路網輸出

附件全文保存在 `docs/north-map-spec.txt`，圖面檢核記錄在 `docs/north-map-checklist.md`，14 輪站距調整與最新 5 遍檢查紀錄在 `docs/north-map-spacing-review.md`。`npm run export:map` 重建 `public/maps/north-relative.svg`，`npm run build` 也會自動更新該檔，確保下載檔與頁面一致。

## 資料與判定

`src/data.js` 是本次對話確認的題庫快照，不會自動追蹤營運變動。包含依使用者指定納入的「廣慈/奉天宮 | 松山慈惠堂」。舊山線、阿里山林鐵與未通車區段不納入現行題庫。

同名車站依系統及實際接線建立識別碼。動物園捷運站與纜車站分開；新埔—新埔民生、北門—台北車站、動物園捷運—纜車，以及高雄凱旋—前鎮之星、凹子底—愛河之心、苓雅運動園區—凱旋公園設有站外步行連接。步行連接在最少站數挑戰中算一段，介面已註明。轉乘不計算時間、票價及實際可搭乘班次。

台鐵支線分類、三鶯線及副站名均沿用本次確認清單。台鐵與捷運互為轉乘提示，但不同大分類之間不做跨系統最短路線。

設定的「練習範圍」在最少站數模式用來限制系統隨機出題的起終點；不可自訂，且至少包含一個中間站。路徑仍以同區域完整路網計算，花蓮港、枋野不作旅客路徑起終點。最佳紀錄依分類、模式、範圍、名稱設定與時限分開比較，針對未熟悉項目的複習另計。

原始到站展示頁備份於 `original-display.html`。

## 檢查

```sh
npm test
npm run test:ui
npm run build
```

測試涵蓋路網連通、分支、環線、同名站識別、等長最短路徑、填空、完整通關、副站名、轉乘與計時結算。

台中捷運不開放最少站數挑戰；切換時若原本使用此模式，會改為全圖限時填空。

台中捷運只採站名，不提供副站名模式。

## GitHub Pages 部署

儲存庫：`EricbobXD/Metro_guest`。在 GitHub 儲存庫的 **Settings → Pages → Source** 選擇 **GitHub Actions**。

推送至 `main` 後，`.github/workflows/deploy.yml` 會安裝鎖定版本的依賴、執行資料與介面測試、建置，再部署 `dist/`。建置失敗不會更新正式網站。

工作流程以 `BASE_PATH=/Metro_guest/` 建置；本機開發仍使用根路徑。SVG 下載與靜態資源會跟隨部署的子路徑。網站使用 hash 導覽，重新整理 `#practice` 或 `#routes` 不需要伺服器改寫規則。

`node_modules/`、`dist/`、本機預覽截圖與環境變數檔不會提交。網站無伺服器資料庫，也不會上傳瀏覽器中的練習紀錄。
